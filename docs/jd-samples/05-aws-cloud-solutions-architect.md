## About the Role
AWS is the world’s most comprehensive and broadly adopted cloud platform. As a Senior Cloud Solutions Architect, you will partner directly with strategic enterprise customers and fast-growing unicorns to design, prototype, and build mission-critical, highly available cloud workloads.

## Key Responsibilities
- Architect well-architected AWS solutions across multi-account, multi-region architectures (VPC peering, Transit Gateway, Route53, IAM governance).
- Lead migration strategies from on-premises and monolithic infrastructures to containerized (EKS, ECS) and serverless (Lambda, EventBridge) topologies.
- Implement Infrastructure as Code (Terraform, AWS CDK, CloudFormation) with automated CI/CD deployment pipelines.
- Author technical whitepapers, architectural decision records (ADRs), and reference architecture guides.

## Required Qualifications
- 4+ years in cloud architecture, systems engineering, or technical consulting.
- Hands-on technical mastery of core AWS services (Compute, Storage, Networking, Security).
- Active AWS Certification (Solutions Architect Professional or DevOps Engineer Professional preferred).
- Proven ability to communicate complex distributed architectures to both CTOs and engineering teams.
