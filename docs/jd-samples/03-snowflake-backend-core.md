## About the Role
Snowflake delivers the Data Cloud — a global platform where thousands of organizations mobilize data with near-unlimited scale, concurrency, and performance. As a Senior Backend Developer on our Compute Engine team, you will design the foundation powering elastic query compilation and execution across multi-cloud environments.

## Key Responsibilities
- Architect multi-tenant query scheduling, resource allocation, and distributed memory management systems.
- Optimize query compilation latencies and disk I/O throughput across petabyte-scale workloads.
- Design fault-tolerant orchestration services in Go and C# / C++ across AWS, Azure, and Google Cloud.
- Build comprehensive profiling, telemetry, and automated self-healing subsystems.

## Required Qualifications
- 5+ years of software engineering experience focusing on high-performance distributed systems.
- Proficient in C#, Go, C++, or Rust with deep knowledge of memory management and concurrency primitives.
- Strong understanding of OS internals, network protocols (gRPC, TCP/IP), and storage tiering.
- Experience with cloud architecture (AWS EC2/S3, Azure VMs/Blob, GCP Compute).
